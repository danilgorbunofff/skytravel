## 5. ✍️ ПОДБОР (квиз, до 9 шагов)

| #   | Вопрос                                                                                          | Кнопки                                                                             |
| --- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 1   | `Куда тянет?`                                                                                   | 🏖 Пляж · 🏛 Экскурсии · ⛷ Горы · 🤷 Посоветуй                                     |
| 2   | `Когда планируете поездку?`                                                                     | 📅 В ближайший месяц · 🗓 Через 1–3 месяца · 🗓 Через 3–6 месяцев · 🌍 Даты гибкие |
| 3   | `На сколько дней едете?`                                                                        | ✈️ 3–5 ночей · 🛫 7–10 ночей · 🏖 11–14 ночей · 🌴 Больше 2 недель                 |
| 4   | `Сколько взрослых едет?`                                                                        | 👤 Один · 👥 Двое · 👨‍👩‍👦 Трое · 👨‍👩‍👧‍👦 Четверо или больше                                |
| 5   | `Дети едут с вами?`                                                                             | 🙅 Нет · ✅ Да                                                                     |
| 6\* | `Сколько детей?` _(если «Да»)_                                                                  | 🧒 Один · 👶 Двое · 👧 Трое · 👦👧 Четверо или больше                              |
| 7\* | `Итого: {состав} — всего N человек. Всё верно?` _(проверка состава)_                            | ✅ Всё верно · ↩️ Изменить состав                                                  |
| 8\* | `Возраст 1-го ребёнка?` … `Возраст N-го ребёнка?` _(по одному радиовопросу на каждого ребёнка)_ | 🍼 0–2 · 🧒 3–7 · 👦 8–12 · 🧑 13+                                                 |
| 9   | `Бюджет на всех?`                                                                               | До 35 000 CZK · 35–45 000 · 45–60 000 · От 60 000 CZK                              |

«Когда» и «надолго» — два отдельных вопроса. Шаг 7 показывает итоговое число человек
и ловит несостыковки; «↩️ Изменить состав» возвращает к вопросу о взрослых,
детские поля сбрасываются, остальные ответы сохраняются.
Возраст спрашивается отдельно для каждого ребёнка (радио-выбор — мис-клик исправляется
одним нажатием). Без детей шаги 6–8 пропускаются.

Финал (пример: мама с ребёнком):

```
✅ Принял! Вот твой подбор:
• Пляж
• Когда: через 1–3 месяца
• Надолго: 7–10 ночей
• Состав: 1 взрослый + 1 ребёнок (3–7 лет) — всего 2 человека
• Бюджет: 40–60 000 CZK (≈ 25 000 CZK на человека)

Пришлю 3 варианта с разбором каждого отеля в течение пары часов.

Хочешь получить подбор быстрее? Жми кнопку — менеджер возьмёт запрос в работу первым.
```

Кнопки: `⚡ Хочу быстрее` (пуш менеджеру «просит ускорить подбор») · `📢 Наша группа с турами`

В БД: `adults`, `children`, `childAges` (читаемый список с группировкой: «3–7 лет ×2», «3–7 лет, 8–12 лет»), `duration` («7-10 ночей»).
Пуш менеджеру: `Состав: … — всего N человек · Надолго: 7-10 ночей · Бюджет: … (≈ N CZK на человека)`.

## 🌐 ДВУЯЗЫЧНОСТЬ (RU + UK)

**Определение языка:** при первом `/start` Telegram присылает `language_code` — `uk*` → украинский, всё остальное → русский. Язык хранится в `bot_leads.lang`.

**Переключение:** кнопка `🌐 Язык/Мова` в меню или команда `/language` → инлайн-кнопки 🇷🇺 Русский | 🇺🇦 Українська. Выбор сохраняется в БД и действует на всё (квиз, дожимы, ответы).

**Хранение в БД — коды, не строки:**
| Поле | Коды |
|---|---|
| direction | beach · tours · mountains · advise |
| travelMonth | month · 1-3 · 3-6 · flex |
| duration | 3-5 · 7-10 · 11-14 · 2w+ |
| budget | <40k · 40-60k · 60-90k · >90k |
| childAges | 0-2 · 3-7 · 8-12 · 13+ |

Подписи кнопок и итоговые сообщения подставляются из словарей `i18n/ru.ts` / `i18n/uk.ts`. Пуш менеджеру и IG-ответы — всегда русские.

**Итог квиза (укр):**

```
✅ Прийняв! Ось твій підбір:
• Екскурсії
• Коли: Через 3–6 місяців
• Надовго: 11–14 ночей
• Склад: 2 дорослих + 1 дитина (3–7 років) — усього 3 людини
• Бюджет: до 40 000 CZK (≈ максимум 13 300 CZK на людину)
```

## ◀️ КНОПКИ НАЗАД (по всему боту)

| Место                               | Кнопка                   | Действие                                                        |
| ----------------------------------- | ------------------------ | --------------------------------------------------------------- |
| Гайд / Горящие / Гейт / Финал квиза | `◀️ В меню`              | Главное меню                                                    |
| Каждый вопрос квиза (кроме первого) | `◀️ Назад`               | Предыдущий вопрос; ответ на него и все последующие сбрасываются |
| Первый вопрос квиза                 | `◀️ В меню`              | Выход из квиза, сессия удаляется                                |
| Смена языка посреди квиза           | session.lang обновляется | Дальнейшие вопросы на новом языке                               |

Сброс при «Назад»:

- к «Когда» → очищается «Когда» (длительность остаётся до повторного ответа)
- к «Взрослые» → очищаются взрослые+дети+возрасты
- к «Дети едут?» → очищаются дети+кол-во+возрасты
- к «Сколько детей» → очищаются кол-во+возрасты
- из бюджета к возрастам → последний возраст убирается

## ✍️ ОСОБЫЕ ПОЖЕЛАНИЯ (финальный шаг квиза)

После бюджета — опциональный шаг:

```
Есть особые пожелания?

Напиши одним сообщением — например: Турция или Египет,
тихий отель, номер с видом на море, детский клуб, первый ряд пляжа…

Или нажми «Пропустить».
```

- Текст пользователя **удаляется из чата** после отправки (чат остаётся чистым)
- Пожелания видны в финальной сводке («• Пожелания: …») и в пуше менеджеру
- Кнопка «⏭ Пропустить» — шаг необязателен
- Обрезка до 1000 символов, HTML-экранирование

## 💬 РЕЖИМ «ОДНО АКТИВНОЕ СООБЩЕНИЕ»

Бот переписывает **одно и то же сообщение** вместо спама новыми:

- Каждый экран (меню, гайд, горящие, гейт, вопросы квиза, финал, подтверждения) рендерится в активном сообщении через `tg/ui.ts → show()`
- **Правило нажатой кнопки:** если нажата кнопка — экран рисуется в сообщении этой кнопки (дожимы-push обновляются сами в себе)
- Клавиатура всегда передаётся; пустой массив = снять кнопки (`/stop`)
- Edit упал (удалено/старше 48ч) → удалить старое → новое сообщение → запомнить id
- «not modified» = успех (защита от двойного тапа)
- Квиз: сверху прогресс-строка `✅ Пляж · ✅ Март · ✅ 7–10 ночей…`
- **Группы игнорируются полностью** (middleware: всё, кроме private, молча отбрасывается)
- Дожимы 3/7/14/30 — единственные отдельные push-сообщения (по дизайну)
