> Итоговая цена инфраструктуры: **0 CZK** — только время.

## ЧАСТЬ 1. ОБЩАЯ АРХИТЕКТУРА (только Telegram + свой сервер)

```
Reels → коммент с кодовым словом в Instagram
   ↓
Meta webhook → POST /webhooks/instagram (твой Express)
   ↓ совпадение ключевого слова
Private Reply в Direct: «Забирай в Telegram → t.me/твой_бот»
   ↓
TG-бот: проверка подписки на канал → меню:
   📕 Гайды · 🔥 Горящие · ✍️ Подбор
   ↓ ветка Подбор: квиз из 4 вопросов (inline-кнопки)
Лид пишется в MariaDB → push тебе в личку → подборка 2–3 тура ≤ 2 ч
   ↓ нет покупки
cron-дожимы день 3 / 7 / 14 + еженедельные рассылки по сегментам
```

**Переходный период (пока идёт App Review Meta):** CTA в Reels ведёт сразу в TG — _«Полный гайд и горящие туры — в нашем Telegram: @бот»_. Кодовые слова включаются одной строкой конфига после одобрения.

## ЧАСТЬ 2. КОДОВЫЕ СЛОВА

По умолчанию — **Набор 1**, вынесены в `bots/src/keywords.ts`, меняются за секунды:

| Слово      | Ветка            | Кто пишет                                      | Варианты опечаток            |
| ---------- | ---------------- | ---------------------------------------------- | ---------------------------- |
| `СПИСОК`   | 📕 Гайды         | Холодные: интерес есть, покупать не собирается | список, сисок, списак, guide |
| `ЦЕНЫ`     | 🔥 Горящие туры  | Тёплые: хотят недорого и скоро                 | цены, цени, цена, price      |
| `ПОДОБЕРИ` | ✍️ Личный подбор | Горячие: готовы покупать                       | подбери, подбор, podbor      |

Правила: короткое, пишется без ошибок на слух, первая буква у трёх слов разная. В BotHelp не нужно — ловим сами в вебхуке.

💡 Бот публично отвечает на комментарий («Ответил вам в Direct 👌») — подсказка человеку + соцдоказательство для читающих.

## ЧАСТЬ 3. ТРИ ВЕТКИ (логика одинакова для IG и прямого входа в TG)

### 📕 Ветка А: ГАЙД (холодные)

1. **Direct/TG:** приветствие → файл выдаётся **после подписки на канал** (проверка getChatMember).
2. После файла мягкий вопрос: _«Куда думаете лететь в этом году?»_ (кнопки-направления) → сегмент-тег для рассылок.
3. Цель: рост базы канала. Продажу не форсим — продаёт контент-матрица 40/30/20/10.

### 🔥 Ветка Б: ЦЕНЫ / горящие (тёплые)

1. Подписка на канал как условие получения текущей подборки горящих.
2. Выдаём свежую подборку (PDF/сообщение со ценами).
3. Сразу 2 вопроса для сегментации: направление? когда примерно?
4. Автоматика: раз в неделю бот шлёт сегменту «Египет» только египетские горящие.
5. Мостик вверх: в каждой подборке кнопка _«✍️ Хочу точнее под мой запрос»_ → ветка В.

### ✍️ Ветка В: ПОДБОР (горячие — приоритет №1)

1. **Никаких барьеров до конца квиза:** 4 вопроса inline-кнопками:
   - направление/тип отдыха? · месяц + длительность? · состав (возраст детей)? · бюджет?
2. Финал: _«Пришлю 3 варианта в течение пары часов. Продублирую сюда же в Telegram: [ссылка]»_ — подписка предлагаем ПОСЛЕ.
3. Тебе мгновенный push со всеми ответами → подборка из 2–3 туров ≤ 2 часов.
4. Дожимы автоматически: день 3 (обзор отелей) · день 7 (отзыв) · день 14 (цены растут).

**Принцип:** чем горячее ветка — тем меньше барьеров.

## ЧАСТЬ 4. ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### Новый воркспейс `bots/` (рядом с `server/` и `client/`)

Отдельный PM2-процесс (~30–50 MB — критично при лимите сервера 450 MB).

```
bots/
├── package.json            # type: module; deps: grammy, node-cron, express
├── tsconfig.json           # как у server (ES2022, ESM .js-импорты!)
├── prisma/schema.prisma    # свои таблицы в той же MariaDB:
│                           #   BotLead     — лиды + сегменты (направление, бюджет, даты, источник)
│                           #   QuizSession — состояния диалога квиза
│                           #   KeywordHit  — статистика кодовых слов (какой Reels работает)
└── src/
    ├── index.ts            # Express: /webhooks/telegram, /webhooks/instagram, /health
    ├── config.ts           # все настройки из .env
    ├── keywords.ts         # кодовые слова + варианты написания
    ├── tg/
    │   ├── bot.ts          # grammY через webhook (не polling)
    │   ├── subscribe.ts    # getChatMember → проверка подписки на канал
    │   ├── files.ts        # выдача PDF гайдов и подборок горящих
    │   └── quiz.ts         # state machine квиза → лид в БД → push владельцу
    ├── ig/
    │   ├── webhook.ts      # GET-верификация hub.challenge + POST события comments
    │   └── graph.ts        # Private Reply в Direct через Graph API
    └── crons/
        ├── followups.ts    # дожимы день 3/7/14 по лидам без брони
        └── report.ts       # недельный отчёт воронки тебе в TG
```

### Переменные окружения (.env бота)

| Переменная           | Что это                                          |
| -------------------- | ------------------------------------------------ |
| `BOT_PORT`           | Порт процесса (например, 3005)                   |
| `TELEGRAM_BOT_TOKEN` | Токен от @BotFather                              |
| `OWNER_CHAT_ID`      | Твой личный TG chat_id для push-уведомлений      |
| `CHANNEL_ID`         | ID/юзернейм канала для проверки подписки         |
| `IG_VERIFY_TOKEN`    | Произвольная строка для верификации вебхука Meta |
| `META_APP_SECRET`    | Secret из Meta Developer App (валидация подписи) |
| `META_PAGE_TOKEN`    | Page access token (после App Review)             |
| `IG_USER_ID`         | ID твоего IG-бизнес-аккаунта                     |
| `PDF_DIR`            | Путь к папке с PDF-файлами гайдов/подборок       |

### Инфраструктура

- **nginx:** `location /webhooks/` → прокси на `BOT_PORT` (HTTPS уже есть):

```nginx
location /webhooks/ {
    proxy_pass http://127.0.0.1:3005;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

- **PM2:** процесс `skytravel-bots` уже добавлен в `ecosystem.config.cjs` (max_memory 256M, порт 3005).
- **База:** те же учётные данные MariaDB; таблицы (`bot_leads`, `bot_quiz_sessions`, `bot_keyword_hits`) создаются автоматически при старте — миграции не нужны, конфликтов с миграциями сервера нет.
- **Запуск в разработке:** `npm run dev:bots` из корня репозитория.

## ЧАСТЬ 6. ПОРЯДОК РАЗРАБОТКИ

1. Скелет `bots/` + Prisma-модели + миграция
2. TG-бот целиком: меню → подписка → гайды/горящие → квиз → уведомления → дожимы _(работает сразу)_
3. IG-webhook: код готов, активируется токенами после одобрения Meta
4. Cron-рассылки по сегментам + недельный отчёт
5. Документация, lint, деплой

## ⚠️ Предупреждения

1. **Только официальный Instagram API.** Неофициальные библиотеки (instagram-private-api и т.п.) на бизнес-аккаунте = риск бана.
2. До App Review IG-часть полноценно не заработает — это нормально, TG-часть независима.
3. Бот держать лёгким: память сервера ограничена (450 MB на основной процесс).
4. Каждое сообщение бота должно вести к следующему шагу воронки — никаких «тупиковых» экранов.
