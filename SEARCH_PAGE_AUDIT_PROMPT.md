# Search Page Audit Prompt

Conduct a comprehensive technical and UX audit of the search page. Analyze it from multiple perspectives: as a software engineer, UI/UX designer, and product developer with extensive experience.

## Scope of Audit

- **Functionality:** Identify incomplete features, broken functionality, or behaviors that deviate from expected outcomes
- **UI/UX Design:** Evaluate visual hierarchy, accessibility, consistency, and user flow
- **Performance:** Assess loading times, rendering efficiency, and responsiveness
- **Code Quality:** Review implementation patterns, architecture, and adherence to project standards
- **User Experience:** Identify friction points, confusing interactions, and missing affordances
- **Edge Cases:** Find unhandled states (errors, empty states, loading states, etc.)
- **Cross-browser & Responsive:** Test behavior across devices and screen sizes

## Deliverables

1. **Detailed Findings:** Document each issue with severity level (critical, high, medium, low)
2. **Root Cause Analysis:** Explain why each issue exists and its impact
3. **Phased Improvement Plan:** Organize fixes into logical phases:
   - **Phase 1:** Critical blockers (breaking functionality)
   - **Phase 2:** High-impact UX/design issues
   - **Phase 3:** Enhancement and polish
   - **Phase 4:** Nice-to-haves and optimizations

## Format

Present findings with clear structure, priorities, and actionable recommendations.
